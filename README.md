*하루비란 하루의 가용 비용을 뜻합니다.*\
*수입일 직후 돈을 마구 지출하여, 한 달이 지날수록 부족하게 생활하신 경험이 있나요?*\
*우리에게는 일정에 따른 지출, 고정 지출 등 예정된 지출이 있습니다.* \
*이들을 미리 알고, 계획할 수 있다면 어떨까요?*\
*하루비는 이 모든 것을 고려한 후 하루에 사용할 수 있는 적절한 금액을 알려주어, 한 달 동안 안정적으로 생활할 수 있게 도와줍니다.*\
*하루비를 통해 쉽고 빠르게 지출 계획을 시작해 보세요.*
